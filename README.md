# ویرایشگر تایل‌های سیاه‌چال (۱۲ شب)

ابزار ساخت و ویرایش تایل‌های سیاه‌چال بازی رومیزی «۱۲ شب». صفحهٔ `index.html` را در مرورگر باز کن (یا لینک GitHub Pages همین مخزن را).

- **ذخیره:** تایل‌ها، تنظیم‌ها و گرافیک‌ها در همان مرورگر ذخیره می‌شوند، نه روی گیت‌هاب. برای نسخهٔ پشتیبان یا بردن به کامپیوتر دیگر، «ذخیرهٔ فایل پروژه» را بزن و بعد با «باز کردن فایل پروژه» برگردان. برای اینکه Claude آخرین تغییرات را ببیند، همین فایل پروژه را برایش بفرست.
- **تنظیمات و گرافیک:** ابعاد تایل، حاشیه، قطر دایره‌ها، ضخامت و رنگ راهروها، توپر یا توخالی، آیکون‌ها، پس‌زمینه‌ها (تصادفی، جدا برای سطح ۱ و ۲)، قاب، و گرافیک دایره‌ای برای هر نوع خانه (تصادفی).
- **راهرو:** هر ترکیبی از تاریک، ریزش‌کرده، طولانی و یک‌طرفه.
- **PDF چاپی:** چیدن تایل‌ها روی A4 با ۳۰۰ dpi، با بلید و علامت برش.

`jspdf.umd.min.js` کتابخانهٔ jsPDF 2.5.1 (مجوز MIT) است که برای ساختن PDF کنار صفحه گذاشته شده.

کدگذاری راهرو در فایل پروژه: `[s|d|x|b][1|2][o|i]?` (s ساده، d تاریک، x ریزش‌کرده، b تاریک و ریزش‌کرده؛ ۲ طولانی؛ o یک‌طرفه از سر اول به دوم، i فقط ورود به تایل).
